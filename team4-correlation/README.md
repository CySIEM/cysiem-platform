# Team 4 - Correlation & Investigation

This package provides a simple starter implementation for correlating security alerts, deduplicating events, calculating severity, and building a timeline for investigation.

## Structure

- correlation/: alert correlation, deduplication, and severity calculation
- investigation/: timeline, root cause, and evidence helpers
- api/: incident analysis API helpers
- models/: data models
- sample_data/: example input data
- tests/: pytest-based regression tests

## Run tests

```bash
pytest
```
